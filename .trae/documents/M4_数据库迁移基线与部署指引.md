# M4｜数据库迁移基线与部署指引

## 结论

- 代码库已引入 Prisma migrations 基线：`apps/api/prisma/migrations/202606060001_init`
- CI 已统一使用 `prisma migrate deploy`（不再使用 `db push --accept-data-loss`）

## 新环境（空库）初始化

在设置好 `DATABASE_URL` 后执行：

```bash
npm -w api run prisma:generate
npm -w api run prisma:migrate:deploy
```

## 已有环境（非空库）接入迁移体系（baseline）

已有数据库之前通过 `db push` 创建过表结构，首次直接跑 `migrate deploy` 可能会因为“表已存在”而失败。需要将 init 迁移标记为已应用：

```bash
npm -w api run prisma:generate
npm -w api exec -- prisma migrate resolve --applied 202606060001_init
npm -w api run prisma:migrate:deploy
npm -w api exec -- prisma migrate status
```

## 约束

- 开发侧新增字段/表必须通过 `prisma migrate dev` 生成迁移文件并提交
- CI/预发/生产环境只允许使用 `prisma migrate deploy` 应用迁移
